Dated notes from development sessions. Each entry captures:

- What happened
- Why it mattered
- What should happen next

Sessions can span hours or days. The goal is continuity between conversations — a fresh agent reading the log should be able to pick up roughly where the last session left off.

Entries sort newest-first by negative ISO date (`order: -YYYYMMDD` in frontmatter).
